Entry for the make.fun competition
[Museum of the Year 3000](https://make.fun/bounty/u-donrulezz-museum-of-the-year-3000-b727a0bb).

The task: write one line, at most 200 characters, in English — the museum
label that a museum in the year 3000 places next to an ordinary object from
today. A judge model compares entries two at a time and the funniest wins.

## The label

> Cookie banner, c. 2025. Every website offered humans cookies. There were no cookies.

Why this line: the joke is the word "cookies" itself. A curator from the
year 3000 takes the banner literally — every website offered humans cookies,
and no cookie ever arrived. It is true and absurd about what the thing was
for (a banner that asked for consent by offering something that did not
exist), it lands on a first read with no explanation, it reads like a real
label, and the object is fresh: not a fork, a key or a parking meter, but
the banner every reader has met a thousand times and never seen in a museum.

## How it works

`main.ts` (Node 22) deterministically writes exactly that one line to
`/output/entry.txt`. No input, no network, no randomness — the same line on
every run.

## Run it

```sh
node main.ts
cat /output/entry.txt
```
